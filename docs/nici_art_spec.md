# NICI 独角兽立绘 · 统一造型规格书 v1

（供文生图/改图使用；目标是让 4 只不同配色的独角兽出自同一套造型逻辑，且经得起与官方商品图逐项比对）

---

## 0. 素材边界（先读，否则后面全错）

判断"哪些不是独角兽形"，是这份规格的第一步：

| 参考 | 实际内容 | 能否作为独角兽身体参考 |
|---|---|---|
| 蓝鬃钥匙扣款 | 真独角兽（短密绒身 + 青蓝长丝鬃 + 金锥 + 银五金） | 可，但属"钥匙扣产品线"，比例偏头重脚轻 |
| 淋面款（紫/粉/奶油三层滴落） | 真独角兽（短密绒身 + 印刷淋面 + 淡粉长毛鬃尾 + 深紫缎面角） | 可，主参考 |
| 米白 + 金网纹角 + 粉鬃款 | 真独角兽 | 可，主参考 |
| 两组"白老鼠坐甜点拉链包" | **不是独角兽**：NICI 白鼠，无角无鬃、无耳尖三角、身体是一体白蛋 | **禁止**迁移其五官/比例 |
| 刺绣抱枕 | 平面刺绣图案，非毛绒工艺 | **禁止**迁移其面料与立体感（但它证明了 NICI 头部结构：低眼位、大额、扁平贴体鬃毛） |

一句话：**只有前三种能做"独角兽身体"的形准依据；后两种只能作配色/标记的旁证。**

## 1. 铁律（违反任何一条就不像 NICI）

**R1 三段材质。** 身体是短密绒，鬃毛和尾巴是另一种长纤维毛，独角是第三种（金属/闪）材质。三者必须一眼可分。这是 NICI 独角兽最强的识别特征，比颜色更重要。

**R2 身体＝短密绒，不是长毛。** 绒长约等于头宽的 2%~3%（成品约 0.4~0.7mm 到 3~4mm），密度高到任何角度都看不到底布；哑光、干爽、无丝光、无镜面高光；没有明显倒毛方向，没有压花、没有烫纹、没有刻意的卷毛圈（圈绒/毛巾线只出现在 2025 钥匙扣那一条产品线）。

**R3 鬃毛/尾巴＝长纤维毛。** 单根纤维可辨、长度是身体绒的 3~10 倍；成绺、放射状散开、末端羽化发虚；半透明，受光处几乎褪成白；比身体更亮、更透、饱和度更高。体积靠"纤维细密 + 半透明 + 叠层阴影"造，不靠圆柱体。

**R4 眼睛小，且是全身最深的一点。** 眼径不超过头宽的 11%；纯黑偏灰（#3C3B39~#232323），**没有眼白、没有虹膜、没有瞳孔/眼白的分界**；反光是一片柔和的弥散灰蓝光泽（最亮也只到约 #73767D），不是硬边白高光点。

**R5 口鼻是圆钝凸球，表情极淡。** 吻部向前下方鼓出，是头上最大的单个曲面；鼻/嘴只以一条面料接缝弧 + 一小撮高饱和粉色"亲亲"绣块 + 一条极细缝线笑弧表现，绝不出现鼻梁线、鼻孔大黑点、脸颊深色弧线。

**R6 无蹄。** 四条腿是等粗短圆柱，末端略微外扩后圆钝收口，**无蹄形、无分趾、无脚掌垫、无脚尖色带**（"粉色袜子圈"是当前立绘虚构出来的，真品上没有）。

**R7 矮胖、无脖子。** 头与身体直接相连，头宽≈躯干宽，头身比≈1:1；头高占总高约 34%~50%，腿长只占体高约 20%~26%。整体轮廓是"横放的圆角楔形/矮蛋"，加上鬃尾后视觉上"宽≈高"。

**R8 独角是短粗钝头锥。** 长:底宽 ≈ 1.4:1 ~ 2.5:1，基本竖直、最多前倾/后仰 4°~25°，**顶端是圆钝收口，不是尖针**，不弯或只在尖端有极轻微弯钩感。

**R9 留白面板。** 口鼻球、包住眼睛的椭圆颊片、耳朵外侧三块**不印图案**；图案只长在颅顶、颈、身体"兜帽"区。

**R10 光。** 单一柔光源（大面积散射），明暗是宽而缓的连续渐变；无硬高光、无镜面反射、无锐利反光点；地面只有极淡的柔和接触阴影。

**R11 标记是刺绣，不是平涂。** 腹部/臀部标记为缎面绣或贴布绣：边缘清晰或略锯齿、微微凸起、内部能看到同向的斜针脚方向感，**不是边缘发虚的实心色块**。

## 2. 逐项规格（可直接进提示词）

### 2.1 面料
- 写实描述：`short dense plush / minky-velboa pile, ~2-3% of head width fiber length, matte, no visible backing, no directional nap, no embossing`
- 提示词措辞（中）："身体为短密哑光毛绒，绒毛极短极密，看不到底布，无倒毛方向，无压花纹理，表面呈均匀细腻的雾面颗粒感"
- 提示词措辞（英）：`matte short-pile plush body, dense, no backing visible, no directional sheen, soft microfiber grain`

### 2.2 眼睛
- 写实描述：小、黑、无分界、凸面、嵌入式、四周有绒毛咬边
- 提示词措辞（中）："小颗嵌入式黑色安全眼，直径约为头宽的 8%~10%，纯黑近圆、看不到眼白与瞳孔分界，表面只有一片柔和弥散的反光，眼周一圈白绒毛微微咬住眼球边缘，位置靠上靠前（头顶往下约 15%~23%）"
- 提示词措辞（英）：`small embedded black safety eyes, ~8-10% of head width, no sclera, no iris split, matte diffuse highlight, plush fibers biting the edges`

### 2.3 口鼻
- 写实描述：圆钝凸出的吻球；接缝弧在吻根；微凸的粉色"亲亲"绣块居中偏上；极细缝线笑弧
- 提示词措辞（中）："吻部向前下方鼓出一个圆钝的球，是整张脸最大的曲面；吻根处有一条隆起约 1px 的拼接压线，弯成一道上扬的笑弧；鼻嘴位置是一小撮高饱和粉色缎面绣块（约头宽的 6%~8%）加一条极细浅色缝线，除此之外脸上没有任何深色标记，没有鼻梁线，没有鼻孔黑点"
- 提示词措辞（英）：`rounded protruding muzzle ball, subtle seam arc at the muzzle base, tiny saturated pink satin-stitch kiss mark, hairline embroidered smile, no nostril dots, no nose bridge line`

### 2.4 鬃毛
- 写实描述：长纤维毛片，从两耳之间/独角后方起，成绺、有走向，末端羽化；形态分产品线（见 3.4）
- 提示词措辞（中）："鬃毛是另一种长纤维毛料，单根丝状可辨、成绺蓬散、边缘羽化发虚，受光处几乎褪成白、叠层处压出深色；从两耳之间与独角后方长出，覆盖颈背，与白色身体形成明显的材质反差；不是一撮撮分开的尖角，也不是圆头香肠瓣"
- 提示词措辞（英）：`long-pile faux-fur mane, individually visible fibers, wispy feathered edges, semi-translucent highlights, material contrast against the short-pile body, strand-locked not cartoon-scalloped`

### 2.5 尾巴
- 写实描述：臀后一整团/一整片长毛，体积大于或等于头，向下并微向外撇；纤维比鬃毛更长更蓬
- 提示词措辞（中）："尾巴是臀后一整团蓬松长毛，横向宽度约等于头宽，向下垂并微微外撇，纤维比鬃毛更长更散、末端呈细丝状羽化，不是圆球、不是贴身的扁三角"
- 提示词措辞（英）：`large fluffy long-pile tail plume behind the rump, width ≈ head width, drooping and flaring slightly outward, feathered fiber tips, not a round ball`

### 2.6 独角
- 写实描述：短粗直立钝头锥，底面直接插进额头绒毛，无金属环、无底座、无刻度环
- 提示词措辞（中）："独角为短粗直立的圆锥，长约为底宽的 1.5~2.5 倍，均匀收细到一个圆钝的顶，基本竖直；表面有浅螺旋/棱纹，直接插进额头顶层绒毛里，根部没有金属环、没有底座、没有装饰箍"
- 提示词措辞（英）：`short stubby horn, height ≈ 1.5-2.5× base width, rounded blunt tip, nearly vertical, shallow spiral ridge, rooted directly into forehead fur, no collar, no base ring`

### 2.7 身体比例
- 写实描述：头大、身短、腿短；无脖子；背线平缓
- 提示词措辞（中）："头部明显偏大，头宽约等于躯干宽，头与身体直接相连没有脖子；躯干是矮胖的圆浑楔形，背线平缓无驼峰；四条腿极短（离地高度占体高约 20%），等粗、末端圆钝；整体是四足站立、重心偏低、敦实可爱的轮廓，绝不修长"
- 提示词措辞（英）：`oversized head ≈ body width, no neck, squat rounded-wedge torso, flat gentle backline, four very short equal-thickness stubby legs, chunky and grounded` 

### 2.8 配色系统
- 写实描述：身体＝高明度、极低饱和的暖白/奶白（受光 #F7F2E7 级，暗部 #E9E2D3 级）；鬃尾＝同一色相但饱和度和明度都拔高，是全图最抢眼的两块颜色；独角/内耳/标记＝第三组色
- 关键比例：**大面积留给低饱和身体，饱和只出现在极小的面积（鬃尾、角、标记、口鼻粉点）**。官方商品图实测全身 meanS 仅 2%~9%，就是这个结构。
- 提示词措辞（中）："身体大面积是高明度低饱和的暖白；饱和度只集中在鬃毛、尾巴、独角与标记上；整体明暗对比低，阴影是柔和的浅灰而非黑"
- 提示词措辞（英）：`high-key low-saturation body, saturation reserved for mane/tail/horn/mark only, soft low-contrast shadow, no pure black`

## 3. 矛盾项与取舍

### 3.1 眼睛：贴片式 vs 纯黑塑料珠（最大分歧）
- A 说（钥匙扣款 + 旁证）：白色/米色椭圆眼片压在脸上，内嵌一颗小黑瞳（约眼片宽 45%），眼片宽约头宽 20%~30%，眼片外圈有一整圈黑色细绣线包边。
- B 说（淋面款）：整颗纯黑半球塑料珠，眼径仅头宽 5.7%~8%，无眼片、无瞳孔分界。
- **倾向 A（眼片式）**，理由：① A 被两处独立观察交叉印证；② 眼片式是 NICI 独角兽最可辨认的脸部签名，B 描写的可能只是某条产品线的简化做法或被压暗的照片；③ 游戏立绘在 66% 高度下渲染，眼片比 6% 的小黑珠更抗缩略、更可读。
- 采 A 时保留 B 的正确结论：**瞳孔仍然要小、要偏置、不要高光点、不要外扩描边**。黑珠版的"无眼白无虹膜"这一点作为反错误提示保留。

### 3.2 独角材质
- 出现三种说法：金色菱形网纱（金属织物感、非电镀）、金色金属漆 + 闪粉（颗粒反光）、深茄紫缎面 + 3 道浅粉细绳缠绕。
- **倾向：按产品线分别采信，不混用。** 建议把「金色金属网纱 + 粉色缠绳」定为米白/粉系的默认；「深紫缎面 + 粉绳」只在紫系个体上使用。共同铁律（R8、R9）不变：短粗钝头、无底座无金环、浅螺旋/网纹、非镜面。
- 若 100% 还原某一只具体 SKU，**以该 SKU 照片为准**，不要跨款借用角。

### 3.3 有无鼻嘴
- 一组说"脸上只有两颗眼珠，无鼻无嘴，只有一条拼接缝"；另一组说"粉色鼻孔点 + 粉色椭圆嘴片"；诊断又指出官方是"嘴筒上一小撮高饱和粉色亲亲绣块 + 极细缝线笑弧"。
- **倾向：保留极小的粉色亲亲绣块 + 细缝线笑弧，但不保留鼻孔黑点。** 理由：这是 NICI 的招牌"亲亲"表情，且当前立绘正是栽在这里（画成脸颊深色弧线、或两个粉色圆斑）；同时保持 R5 的"极淡"约束，避免又变成写实动物脸。

### 3.4 鬃毛形态：竖立脊 vs 低垂贴伏
- 钥匙扣款是"高耸竖立的脊状毛峰"，淋面款/抱枕是"低垂贴伏的整体毛片，不成绺、不竖立"。
- **倾向：游戏采用"低伏铺开 + 前额一小撮立起"的折中**。理由：竖立大毛峰会显著改变剪影高度，而游戏舞台是**高度锁定**的（`.uni-wrap{height:66%}`），竖立鬃毛会让 4 只的相对尺寸被宽度差异放大；低伏毛片的高宽比更稳定，四只并排更整齐。前额保留一小撮立毛以保住"鬃毛是另一种材质"的识别点。

### 3.5 内耳
- 亮片（玫瑰金/银粉）、珊瑚粉斜纹布、粉色绣垫、光滑米白。**倾向：粉色系个体用亮片，白/冷色系个体用粉色绣垫**，避免出现"完全没有粉色内耳"的版本（当前立绘 cloudy 就是光面米白大椭圆内耳，是明显失真）。

### 3.6 面料工艺
- 官方横跨三条线：软短绒、圈绒/毛巾线（2025 钥匙扣）、闪粉植绒（2022）。同一套立绘里混用会造成"颗粒噪点 vs 柔糊"的观感割裂。**倾向：4 只统一到"软短绒 + 鬃尾长毛"这一条工艺**，闪粉只作为可选的、极轻的表面微闪，不做成植绒颗粒。

### 3.7 朝向
- 实际素材是三条朝右、一条朝左。**倾向：统一为四分之三左前视角、脸朝画面右侧或左侧任选其一，但四条必须一致。** 这是四条并排时"看出是同一套角色"的最低成本。

### 3.8 与 UI 的衔接（附带的硬事实）
- UI 底色饱和度只有 8%~12%、场景 meanS 约 33%。也就是说主体不需要、也不应该靠高饱和去抢戏；**饱和度只给鬃尾和标记**，身体保持低饱和高亮度，才能和玻璃拟态 UI 共存。
- 代码里的 body/mane/mark 等颜色 token **在别处一次都没被引用**，对渲染零影响。所以"立绘迁就 UI 配色"这条接口目前不存在——**规格书里锁死的颜色，必须直接写进生图提示词**，不要指望 UI 变量。

## 4. 必须避免的画法（反提示词清单）

直接对应当前立绘"不像"的根因：

1. **禁止长毛身体**。全身毛发画成一根根飘逸丝状、或画成均匀 minky 平滑绒面，都不对；身体必须短密，长毛只留鬃尾。
2. **禁止动漫大眼**。不要大眼片、不要高光点、不要睫毛、不要让瞳孔占满眼片（真品瞳/眼片约 45%）；不要出现眼白分界。
3. **禁止圆头香肠瓣鬃毛**。鬃尾不是一节节圆头扇贝叠加，也不是一个圆球尾巴。
4. **禁止腿部色带**。不要给四条腿画"脚尖粉色袜子圈/horizontal band"，真品没有这个元素。
5. **禁止鼻梁线与鼻孔黑点**、禁止脸颊上的深色弧线、禁止把腮红画成两个粉色圆点。
6. **禁止素色软绒锥角**。角上必须有浅螺旋或网纹，必须有材质反差；但不要加金属环、底座、装饰箍。
7. **禁止光滑缎面蝴蝶结**（若该配色有蝴蝶结，官方是格纹布 + 闪边）。
8. **禁止边缘发虚的实心平涂标记**。改为缎面绣：有针脚方向、微凸、边缘略锯齿。
9. **禁止过饱和**。尤其不要把身体染成高饱和粉；不要出现纯黑阴影；不要出现硬边镜面高光。
10. **禁止修长身材**。任何"腿长、脖子长、头小"的版本都直接判错。
11. **禁止中缝/明线**。躯干正面看不出缝合线，缝线被毛盖住。
12. **禁止硬投影片**。地面只要极淡柔和接触阴影；更不要直接在商品图那层影棚灰上再叠游戏 drop-shadow。
13. **禁止把白鼠款或抱枕款的特征混进来**（无角、无鬃、蛋形一体身、平面绣质感）。

## 5. 四只配色的分工表

统一结构：**身体（高明度低饱和） + 鬃/尾（饱和，材质反差） + 独角（第三材质） + 标记（缎面绣）**。下面给出建议槽位，具体 hex **必须以各自 SKU 原图重新取样锁定**（当前代码声明的颜色与实际素材偏差极大，不可信）。

| | 身体 | 鬃/尾 | 独角 | 标记 | 特殊 |
|---|---|---|---|---|---|
| 泡泡 bubble | 暖白 #F7F2E7 级 | 中高饱和亮色（如天青 #7FD6E8 级） | 金色金属网纹/闪粉 | 星星（腹部，缎面绣） | 无腮红 |
| 云云 cloudy | 冷白/浅蓝白 #EDF2F8 级 | 蓝紫或青蓝 #9BA8E0 / #6FC9D6 级 | 金色金属网纹 | 彩虹弧绣（后腿外侧偏上） | 内耳亮片 |
| 桃桃 peachy | 粉白暖调 #FBEFF0 级 | 粉 → 白（受光褪白，叠层显粉） | 金色或深紫缎面 + 粉绳 | 宝石/心形绣 | 去掉"蝴蝶结"文案或改成格纹布蝴蝶结 |
| 梦梦 dreamy | 淡紫白 #F1EBF6 级 | 紫 → 粉 | 深紫缎面 + 3 道粉绳 | 与 peachy 必须换成不同形状 | 闪粉绒可作唯一的表面微闪 |

强制约束：
- **四只标记必须互不相同**（不能两只同款）；
- **四只朝向、机位、透视、头身比一致**，只靠颜色和标记区分；
- **宽高比尽量收窄**（目标 ≤1.15 倍跨度）。当前实拍版 1.34 倍会被高度锁定的舞台放成"大小不一"，务必靠统一构图解决；
- **打光方向统一**，且要与场景光源一致（场景光在右上）。当前实拍版三条左侧受光、与背景反向，必须重打光或镜像统一。
