# 🦄 NICI 独角兽 · 魔法小镇

一个 HTML5 独角兽养成小游戏。**单文件、零依赖**，手机和电脑都能直接玩。

👉 **在线玩：https://yeggogg.github.io/nici-town/**

## 玩法

先选一只独角兽当伙伴 —— 四只的性格和数值特长都不一样：

| 伙伴 | 外观 | 特长 |
|:---|:---|:---|
| **泡泡** Bubble | 雪白 + 粉色鬃毛，星星记号 | 掉心情最慢 |
| **云宝** Cloudy | 淡蓝 + 蓝紫鬃毛，云朵记号 | 吃草量 +12% |
| **桃桃** Peachy | 粉红 + 蝴蝶结，爱心记号 | 玩耍加心情 +35% |
| **梦梦** Dreamy | 淡粉 + 紫鬃毛，菱形记号 | 生长度获取 +20% |

### 三条指标

- 💗 **开心度** —— 每秒自然衰减。饿了掉得更快，吃饱了反而慢慢回升。
- 🌿 **饱食度** —— 持续消耗，喂草补充。草地每 14 秒自动长一根草。
- ✨ **生长度** —— 由**饱食度 × 开心度**共同决定积累速度。

### 关键机制

**开心度直接决定吃草效率**：

```
效率 = 0.35 + 0.95 × 开心度%
```

范围 0.35× ~ 1.30×。开心的时候一根草能填 17 点饱食度，心情崩了只能填 4~5 点。所以想让它长得快，得**又喂饱又哄开心**。

### 每天可以做的事

| 动作 | 效果 | 次数 |
|:---|:---|:---|
| 🌿 喂草 | 补充饱食度，小幅加心情 | 看草地存量 |
| 🤚 抚摸 | 开心度 +18 | 1 次/天 |
| 🎠 玩耍 | 开心度 +26，消耗 7 点饱食度 | 2 次/天 |

跨天按**真实日期**判定 —— 第二天打开会自动补满次数，并赠送 6 根草。

### 魔法礼品

生长度攒满一次，等级 +1，从 **13 件魔法礼品**里随机掉一件（普通 8 种 / 稀有 4 种 / 传说 3 种，带权重），附带开箱动画和音效。

## 技术说明

- **单文件**：[index.html](index.html) 包含全部 HTML / CSS / JS
- **零依赖**：没有框架、没有构建步骤、没有外部 CDN
- **音效**：用 WebAudio 现场合成，不含任何音频文件
- **存档**：localStorage 自动保存（每 6 秒 + 页面关闭时）

### 美术素材

独角兽立绘和场景背景由 `gpt-image-2.5-sunburst` 生成，见 [assets/](assets/)。

原始 PNG 每张 1.3–2 MB，经 [tools/optimize_assets.py](tools/optimize_assets.py) 做三步处理后压到 0.36 MB（省 95%）：

1. 按 alpha 内容边界裁掉空白
2. 统一画布比例、底部对齐 —— 四只脚踩在同一水平线上
3. 缩放到 2x 视网膜足够的分辨率并转 WebP

```bash
py -3 tools/optimize_assets.py    # 重新生成 assets/opt/ 下的素材
```

### 调数值

游戏平衡参数集中在 [index.html](index.html) 的 `CFG` 对象里（衰减速度、加成、草地刷新间隔），加新礼物就往 `GIFTS` 数组里塞一行。

## 本地运行

直接双击 `index.html` 即可。若要用本地服务器：

```bash
py -3 -m http.server 5180
```
